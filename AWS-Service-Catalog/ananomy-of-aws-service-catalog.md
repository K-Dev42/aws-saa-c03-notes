There two side
1. Admin user
2. End user

### Admin users
- They create portfolio in the catalog(container for products, permissions, and constraints)
    - Product is a cloudFormation Template
    - Permissions is who can view or lauch products
    - Constraints apply rules on provisioned products. There are 5 different rules 


### End users
- These guys uses the catalogs
- For the products in the portfolio, end users have access to Service Actions (which are SSM documents associated with a product that allow the end user to perform mainenance)
