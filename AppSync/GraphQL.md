## Definition
GraphQL is an open-source agnostic query adaptor that allows you to query data from many different data sources. 

GraphQL is used to build APIs where client will send a query for nested data

GraphQL mitigates the issue of versioned or rapidly changing APIs compared to REST API because you can request the data you want

GraphQL schemas are written in the GraphQL SDL (Schema Definition Language) composed of
- Types: represent objects and their fields
- Fields
- Queries: defines the exact shape of the data needed by the client
- Mutations: allows for data to be created, updated, or deleted
- Subscription: supports live updates sent from the server to the client
