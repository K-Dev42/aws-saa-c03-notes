## Definition of CLI
A command line interface (CLI) processes commands to a computer program in the form of lines of text. Operating systems implement a command-line interface in a shell. 

**What is a terminal?**
A terminal is a text only interface (input/output environment)

**What is a console?**
A console is a physical computer to physically input information into a terminal. Can also refers to web browser that has web applications that interact with programs 

**What is a shell?**
A shell is the command line program that users interact with to input commands. Popular shell programs:
- Bash
- Zsh
- PowerShell

> People generally use Terminal, Shell, or Console to generally describe interacting with a Shell. 

### Definition of AWS CLI
AWS command line interface allows users to programmatically interact with the AWS CLI via entering single or multi-line commands into a shell or terminal 

You need Python to run AWS CLI
