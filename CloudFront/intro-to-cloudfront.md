## Definition

Content Delivery Network (CDN)
A CDN is a distributed network of servers that deliver web pages and content to users based on their geographical locaion, the origin of the webpage, and a content delivery server. 

> Essentially this is a global cache

CloudFront is a CDN that can be use to deliver:
- Static content
- Dynamic content
- Streaming videos
- Web sockets

Amazon CloudFront can be fronted with AWS WAF for OWASP TOP 10 protection 

Amazon CloudFront can stream Videos On Demand using ISS Microsoft Smooth Streaming
