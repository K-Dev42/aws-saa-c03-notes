## Definition
Amazon FSx allows you to deploy scale feature-rich, high-performance file systems in the cloud. 

FSx supports a variety of file system protocols. 

1. Amazon FSx for NetApp ONTAP
Propriety enterprise storage platform known for handling petabytes of data

2. Amazon FSx for OpenZFS
Open-source storage patform originally developed by Sun Microsystems

3. Amazon FSx for Windows File Server (WFS)
File storage on a windows server supporting native window features for Windows developers 

4. Amazon FSx for Lustre
Open-source file system for parallel computing
