## Definition
Amazon FSx for Window File Server (WFS) is a fully managed shared storage built on Windows server 

- Native support for windows file system eg. SMB
- Native windows compatibility
- Enterprise performance and features
- Consistent sub-milisecond latencies
- Tools that windows developers and administrators use today can continue to work unchanged
- Offers storage backed by SSD, HDD or both
- FSx intergrate with you Microsoft Active Directory

Amazon FSx can be used for:
- Business applications
- Home directories
- Web serving
- Content management
- Data analytics
- Software build setups
- Media processing workloads

To run Amazon FSx you'll need:
- EC2 instance
- Workspace instance
- AppStream 2.0 
or
- VMWare Cloud on AWS
