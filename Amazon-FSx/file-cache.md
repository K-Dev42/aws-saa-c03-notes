## Definition
Amazon File Cache is a high-speed cache for datasets stored anywhere, accelerate cloud bursting workloads. 

Serve as a temporary, high performance storage location for data that's stored in:
- On-premises file systems
- AWS file systems 
- Amazon S3 Buckets

Make dispersed datasets available to file-based applications on AWS with a unified view, and at high speeds (sub-milisecond) latencies and high throughput. 

Amazon file cache is accessible to: EC2, ECS, EKS

Compatible with the most popular Linux-based AMIs:
- Amazon Linux, Amazon Linux 2
- Red Hat Enterprise Linux (RHEL)
- CentOS
- Rocky Linux
- Ubuntu

Integrates with AWS Batch via EC2 Launch templates
Integrates with AWS Thinkbox Deadline
- creative studios scale rendering workloads
