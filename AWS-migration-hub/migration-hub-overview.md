## Definition
AWS Migration Hub is a single place to discover your existing server, plan migrations, and track the status of each application migration.

AWS Migration Hub an monitor migration statis from migration servers:
- Application Migration Service (AMS)
- Database Migration Service (DMS) 

AWS Discovery Agent: an agent installed on your VM of servers to help discover and migrate servers

Migration Evaluator Collector: you submit a request to AWS to help with migration

AWS Migration Hub Refractor: Bridges networking across AWS accounts so that legacy and new services can communicae while they maintain the independence of separate accounts
