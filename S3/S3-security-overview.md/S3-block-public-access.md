**Block public access** is a safety feature that enabled by default to block all public access to an S3 bucket.

The main problem that this addess is: giving the public *unrestricted access* which in-tern is the #1 security misconfiguration. 

There are four options:
1. New access control list (ACLs)
2. Any access control lists
3. New bucket policies or access points 
4. Any bucket policies or access points 

> Access point can have their own independent Block Public Access setting
