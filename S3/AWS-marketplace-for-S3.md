## Definition
The AWS marketplace for S3 provides alternatives to AWS services that work with Amazon S3 

1. Storage backup and recovery
AWS services
- FSx for lustre
- Tape Gateway
- File gateway

Third-party services
- Veeam Backup for AWS
- Druva: AWS Backup and Disaster recovery

2. Data integration and analytics
AWS services
- Transfer family
- DataSync
- Athena

Third-party services
- ChaosSearch
- Logz.io
- ByteFlow Enterprise Edition

3. Observability and monitoring
AWS services
- CloudTrail
- CloudWatch

Third-party services
- DataDog, Splunk, Dynatrace 

4. Security and threat detection
AWS services
- GuardDuty
- Macie

Third-party services
- Trend Cloud One
- InsightDR (Rapid 7)
- VM-series virtual next generation firewalls (NGFW) (Palto Alto Networks)

5. Permissions
AWS services
- IAM

Third-party services
- OneLogin Workforce identity
- FileCloud EFSS
- Yarkon S3 server
