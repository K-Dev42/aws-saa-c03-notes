## Definition
Elastic Compute Cloud (EC2) is a highly configurable virtual server. EC2 is resizeable compute capacity. It takes **minutes** to launch new instances. 

Anything and everything on AWS uses EC2 instance underneath. 

How to spin up an EC2 instance:
- Choose an OS via Amazon Machine Image (AMI)
- Choose Instance Type
- Add storage (EBS, EFS)
- Configure Instance
