## Definition
Amazon Linux is AWS's managed Linux distribution and it is based off CentOS and Fedora which in turn is based off Red Hat Linux (RHEL)

There are multiple versions of Amazon Linux
- Amazon Linux (AL1) (end of life Dec 2023)
- Amazon Linux 2 (AL2)
- Amazon Linux 2023 (AL2023) 

AWS hardens and maintains Amazon Linux

Amazon Linux often has direct support or the only choice for specific AWS services as the underlying OS

AWS provides better technical support via AWS support for Amazon Linux distribution vs non AWS OS distributions
