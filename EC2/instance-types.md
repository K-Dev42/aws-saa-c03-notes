## Definition

The instance type naming convention is as follows:

c7gn.xlarge

c : instance family which is the intended workflow that is designed to meet

7 : the instance generation, it is the version of the family offerings or in other words hardware (newer means better)

g : the processor family which is the specific type of processor 

n : additional capability which indicates what extra features this instance-type has eg. extra storage

xlarge : decides the amount of virtual resources eg. vCPU and RAM

> Some parts of the instance type may be omitted. Eg t3.micro does not contain Processor Family or Additional Capacity
