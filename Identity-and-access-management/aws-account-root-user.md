## Definition
In an AWS account, the root user is a special user who has full access and can not be deleted

Admin tasks that only Root user can perform:
- Change your account settings (include: account name, email address, root user password, and root user access keys)
- Restore IAM user permission
    - If the only IAM administrator accidentally revokes their own permission, you can sign in as the root user to edit policies and restore those permissions 
- Activate IAM access to the billing and cost management cosole
- View certain tax invoices
- **Close your AWS account**
- **Change or cancel AWS support plan**
- Register as a seller in the Reserved Instance Marketplace
- Enable MFA Delete on an S3 bucket 
- Sign up for GovCloud
