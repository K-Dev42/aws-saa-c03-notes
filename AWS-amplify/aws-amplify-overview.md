## Definition
AWS Amplify is an opinionated framework and fully-managed infrastructure to allow developers to focus on building web and mobile applications 

This is considered an umbrella term that encapsulate a lot of things
1. AWS Amplify CLI: unified toolchain to create, integrate, and manage the AWS cloud services 

2. AWS Amplify SDK: connects AWS services to your client-side code

3. AWS Amplify UI: a collection of accessible, themeable, performant React component directly connect to cloud 

4. AWS Amplify Hosting: a static website hosting platform

5. AWS Amplify Studio: visual development environment fr building fullstack web and mobile app

AWS Amplify has direct integration with:
- Amazon Cognito: for auth sign in and sign up
- API Gateway: for rest APIs
- AppSync: for GraphQL APIs
- S3: for storage or for static website hosting
- DynamoDB: for a backend database
- AWS Lambda: custom resolver

> AWS Amplify (Gen 2) is currently in preview and made completely change the experience of AWS Amplify.
