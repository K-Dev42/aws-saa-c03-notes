## Definition
Similar to Snowcone but with more local processing, edge-computing workloads, and device configuration options

Snowball Edge features:
- LCD display (shipping information and other functionality)
- Can use is a cluster in groups of 3 to 16 nodes
- Supports data transfer protocols:
    - NFSv3, NFSv4, NFSv4.1
    - Amazon S3 over HTTP or HTTPS

There are 5 device configuration options
1. Storage-Optimized (for data transfer): 100 TB (80 TB usable)

2. Storage-Optimized 210 TB: 210 TB of usable storage

3. Storage-Optimized with EC2-Compatible Compute: Up to 80 TB usable storage, 40 vCPUs, and 80 GB of memory

4. Compute-Optimized: Up to 104 vCPUs, 416 GB of memory, an 28 TB of dedicated NVMe SSD

5. Compute Optimized with GPU: has the addition of GPUs equivalent to the one available in the Instance Type P3
