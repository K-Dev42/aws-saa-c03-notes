## Definition
AWS Snowcone is a portable, rugged, and secure device for edge computing and data transfer.

Snowcone can send data to AWS in two ways:
- Physically shipping the device back to AWS
- AWS DataSync which runs on the device's compute

Snowcone has two variants:
- Snowcone: 8 TB HDD
- Snowcone SSD: 14 TB SSD

Device can run edge computing workloads that use EC2 instances

Small and light enough to carry in a backpack

Use it with battery-based operation

Use the Wi-Fi interface to gather sensor data (only in North America regions)

Offer an interfacee with Network File System (NFS) support for Windows, Linux and macOS 

Multiple layer of security encryption capabilities

Can be used in space-constrained environment where Snowball Edge devices don't fit 

Can collect IoT data using AWS IoT Greengrass
