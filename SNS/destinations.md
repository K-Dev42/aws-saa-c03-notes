## Definition
Destinations are the subscribers who can receive messages

1. Application-to-Application (A2A)
supports subsribers from AWS services of web-applications 
- Data Firehose
- Lambda Functions
- SQS Queue
- HTTP/S endpoint
- AWS Event Fork Pipelines

2. Application-to-Person (A2P)
supports subscribers from human-entities
- Mobile applications
- Mobile phone number  (SMS aka text messaging)
- Email Address
- AWS chatbot
- PagerDuty
