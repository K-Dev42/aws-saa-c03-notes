## Definition 

1. Deregister 
This is when you're done using an AMI and you don't want to allow any new instances to be launched with the AMI. However, deregistering does not delete snapshots

2. Deprecating 
an AMI allows you to mark a date when it will not be allowed to use

3. Disabling
an AMI prevents the AMI from being used. It can be reenabled at a later point
